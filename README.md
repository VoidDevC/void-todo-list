# void-todo-list


Void Todo List is a simple command-line To-Do List application written in C.

It allows you to:

- Add tasks.
- Store tasks in a text file.
- Display your saved tasks.

## Version

This project is currently in version `v0.1.0` and is still in the pre-alpha stage.

The application is not complete yet, and more features may be added in the future.

## Installation

Clone the repository:

```bash
git clone https://github.com/VoidDevC/void-todo-list.git
```

Enter the project directory:

```bash
cd void-todo-list
```

Give the program execution permission:

```bash
chmod +x voidtodo
```

## Usage

Run the program:

```bash
./voidtodo
```

You must run the command from inside the `void-todo-list` directory.

## Example

```text
=======================
WELCOME TO VOID's TO-DO LIST
=======================

Enter a task: Learn C
Do you want add new task? (yes or no): no
Do you want to see your tasks? (yes or no): yes

Learn C
```

## Requirements

This repository currently contains a precompiled Linux executable.

To run it, you need:

- A Linux system.
- A compatible system architecture, such as x86-64.
- Permission to execute the file.
