# void-todo-list

Void-to-do it simple To-Do List CLI tool.

It support Add tasks , storing them in text file and show your tasks.

for now this tool in v0.1.0 pre-alpha version
the app is not complete for now.

to install Void-to-do

```bash
https://github.com/VoidDevC/void-todo-list
cd void-todo-list/
```
for run the tool 
```bash
chmod +x voidtodo
./voidtodo
```
*** for run this tool you will be into /void-todo-list folder ***
